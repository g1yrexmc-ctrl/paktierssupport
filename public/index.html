Quick setup
1. Select a log channel in Server Settings.
2. Choose support roles and a ticket category.
3. Publish a ticket panel in Panel Maker.
4. Invite the bot with the required permissions and keep its role above members it moderates.
No command uses eval or executes arbitrary JavaScript. Keep your bot token and dashboard password private.
